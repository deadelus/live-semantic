1 LiveSemantic — maquettes GUI (web + desktop)
Hypothèses & parti pris
Densité outil pro (type monitoring), Archivo + Space Mono pour les données. Accent bleu = filtres/actions ; la couleur des box vient du filtre, pas de la catégorie. Le panel Sources est le premier onglet permanent ; chaque source ouverte = un onglet. Le Journal est un tiroir accessible depuis la barre du bas, partout. Vidéo = placeholders hachurés (à remplacer par de vraies captures). Formulaires non demandés (ajout de source) esquissés en flous.
