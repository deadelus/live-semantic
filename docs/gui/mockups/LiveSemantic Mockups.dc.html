3 Révision du modèle — Terme = nom + photos optionnelles, Collections avec tags, autocomplétion v2
Ce qui change vs section 2
Plus trois types de terme : un seul concept TERME = nom (étiquette humaine) + 1…N photos qui portent le sens (vecteurs image CLIP). L'onglet « Galerie » devient « Termes ». Les COLLECTIONS portent des tags plats (jamais d'imbrication) et partagent leurs Termes sans duplication. MODÈLE reste les termes natifs de l'IA. Deux suppressions distinctes : × sur une vignette retire cette photo ; « Supprimer le Terme » retire tout. Les écrans 2a–2e restent comme historique ; 3a–3d les remplacent conceptuellement.

2 Ajouts — modale de source, galerie de références, collections, autocomplétion
Parti pris

Le dropdown d'autocomplétion vit entièrement dans le volet droit (300 px) : il ne recouvre jamais la vidéo. Un terme venu d'une collection reste groupé sous l'en-tête de sa collection dans la liste des filtres actifs (réponse à la question ouverte : oui, on distingue).
